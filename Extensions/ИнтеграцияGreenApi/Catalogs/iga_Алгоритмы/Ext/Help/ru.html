Справочник Алгоритмы


Справочник позволяет создавать алгоритмы, которые затем можно использовать для подстановки в код обработчиков.
Возможно использование в обработчиках команд, обработчиках этапов.
Доступны внешние переменные такие как РезультатОбработки, в него можно передать нужный результат в виде структуры.
Если структура содержит поле ОчиститьПараметры, то произойдет очистка создаваемых параметров после выполнения обработчика 
и установки новый, если передать так же поле НовыеПарметры. Поле НовыеПараметры должно быть типа Структура, где 
Ключ это Имя параметра, а значение это Значение параметра. В дальнейшем в течение этапов можно обращаться к параметрам 
с помощью функции
